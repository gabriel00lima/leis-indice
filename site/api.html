Início

API pública

Metadados e ligações de todas as normas do índice em JSON, de graça e sem cadastro. São arquivos estáticos gerados a cada atualização do índice: basta um fetch.

Endereço base:

https://gabriel00lima.github.io/leis-indice/api/v1/

Todas as respostas são JSON em UTF-8 e podem ser lidas de qualquer site (CORS liberado). Não há chave nem cadastro. O texto das normas não está na API: cada norma traz o link para o Markdown no acervo ctresb/leis.

Experimente 

Escolha o tipo, digite o número e clique em Consultar.

Rotas

RotaO que devolve
index.jsonVisão geral: data da atualização, commit do acervo, totais, jurisdições e listas disponíveis.
normas/{id}.jsonUma norma: metadados, links para o texto e todas as ligações (cita, altera, revoga e o inverso), com os artigos envolvidos.
ref/{jurisdicao}/{prefixo}/{numero}.jsonAcha a norma pelo número, ex. ref/federal/lei/8078.json. Devolve uma lista, porque o mesmo número pode se repetir em anos diferentes.
listas/{lista}.jsonTodas as normas de uma categoria, ex. listas/federal/leis-complementares.json.
busca/{jurisdicao}.jsonTodas as normas da jurisdição num arquivo só, com a ementa resumida, para busca no navegador. busca/federal.json tem uns 7,6 MB (1,4 MB comprimido).

Identificador ({id})

É o caminho do arquivo no acervo sem o .md: federal/leis-ordinarias/1990/lei-8078-1990-09-11. A Constituição de 1988 é constituicao. Quem não sabe o id começa por ref/ ou por busca/.

Prefixos e jurisdições

Prefixos: lei (lei ordinária), lcp (lei complementar), del (decreto-lei), emc (emenda constitucional). Jurisdição: federal hoje. Leis estaduais entram com a sigla da UF em minúsculas (sp, rj, mg) e ids que começam por estaduais/SP/…; o index.json lista o que existe.

Exemplos

JavaScript

const API = "https://gabriel00lima.github.io/leis-indice/api/v1/";

// 1. Achar a Lei 8.078 pelo número
const ref = await fetch(API + "ref/federal/lei/8078.json").then(r => r.json());

// 2. Abrir a norma
const cdc = await fetch(API + ref.normas[0].api).then(r => r.json());
console.log(cdc.titulo, cdc.totais);   // "Lei nº 8.078 de 11/09/1990" { cita: 8, ... }

// 3. Quem alterou o CDC, e em quais artigos
for (const l of cdc.ligacoes.alterada_por) console.log(l.titulo, l.dispositivos ?? []);

// 4. O texto, direto do acervo
const texto = await fetch(cdc.texto.markdown).then(r => r.text());

Python

import requests
API = "https://gabriel00lima.github.io/leis-indice/api/v1/"
cf = requests.get(API + "normas/constituicao.json").json()
print(cf["totais"]["alterada_por"], "normas alteraram a Constituição")

Formato

normas/{id}.json

{
  "versao": 1,
  "id": "federal/leis-ordinarias/1990/lei-8078-1990-09-11",
  "titulo": "Lei nº 8.078 de 11/09/1990",
  "tipo": "Lei Ordinária",
  "numero": "8078",
  "data": "1990-09-11",
  "ementa": "Dispõe sobre a proteção do consumidor e dá outras providências.",
  "revogada": false,
  "urn": "urn:lex:br:federal:lei:1990-09-11;8078",
  "apelido": "Código de Defesa do Consumidor",      // só nas leis mais conhecidas
  "jurisdicao": { "esfera": "federal", "uf": null },
  "lista": "federal/leis-ordinarias",
  "texto": { "markdown": "https://raw.githubusercontent.com/ctresb/leis/main/…md", "github": "…" },
  "paginas": { "lei": "…/lei.html?id=…", "grafo": "…/grafo/?id=…" },
  "totais": { "cita": 8, "altera": 1, "revoga": 0, "citada_por": 75, "alterada_por": 16, "revogada_por": 1 },
  "ligacoes": {
    "cita": [
      { "id": "constituicao", "titulo": "Constituição da República…", "tipo": "Constituição",
        "data": "1988-10-05", "revogada": false, "api": "normas/constituicao.json",
        "dispositivos": ["art. 5º", "art. 170"] }
    ],
    "altera": [], "revoga": [], "citada_por": [], "alterada_por": [], "revogada_por": []
  }
}
  • cita, altera e revoga: normas que esta cita, altera ou revoga. Os campos terminados em _por são o caminho inverso.
  • dispositivos: artigos da norma citada, alterada ou revogada, quando identificados. Em alterada_por, são os artigos desta norma que a outra alterou. Ausente quando não identificado ou quando a ligação vale para a norma inteira.
  • api: caminho da norma vizinha, relativo à base. Vizinhos com "indexada": false estão fora do índice (ex. decretos ou externo:dec-4453-1922, citações que não foram achadas no acervo).

listas/… e busca/…

Para ficarem menores, vêm como colunas e linhas:

{ "versao": 1, "total": 239,
  "campos": ["id", "titulo", "tipo", "numero", "data", "revogada", "ementa"],
  "linhas": [["federal/leis-complementares/2000/lcp-101-2000-05-04", "Lei Complementar nº 101 de 04/05/2000",
              "Lei Complementar", "101", "2000-05-04", false, "Estabelece normas de finanças públicas…"]] }

// Para virar objetos:
const normas = dados.linhas.map(l => Object.fromEntries(dados.campos.map((c, i) => [c, l[i]])));

Atualização e limites

  • O índice é atualizado todo dia de manhã a partir do acervo ctresb/leis; index.json traz gerado_em e o commit usado.
  • É só leitura: não há filtros nem paginação no servidor. Para consultas próprias, baixe busca/ ou listas/ e filtre no seu código.
  • As ligações são extraídas automaticamente do texto e podem ter erros. Como explicado em data/README.md, não substitui a publicação oficial.
  • A versão está no caminho (/v1/). Campos novos podem aparecer; mudanças que quebram compatibilidade vão para /v2/.

Código do gerador: api/ no GitHub.
